# 실제 왁뿌볼 만드는 법 (조사 메모, 2026-10-12)

왁뿌볼 = "왁스 부수기 볼". 말랑한 점토 공에 왁스를 입혀 굳히고, 눌러서 왁스 껍질이 바사삭 깨지는
소리·느낌을 즐기는 ASMR 촉감 장난감. 2025년 말 해외 숏폼에서 시작, 지금 방식은 2026년 여름 유행.
완제품 개당 5,000원 이상, 재료 원가는 약 1,000원이라는 계산이 있다.

## 만드는 순서 (2026년 유행 방식)

1. **점토 빚기**: 아이클레이·천사점토를 주물러 부드럽게 한 뒤 동그랗게.
2. **색 넣기**: 색 점토를 섞어 새 색을 만든다. 덜 섞고 꼬아 둥글리면 마블 무늬. 유성매직으로 칠하기도 한다.
3. **양초 녹이기**: 다이소 양초를 잘라 중탕 또는 전자레인지.
4. **왁스 입히기**: 붓거나 담가서 2~3겹, 완전히 굳힌다 (덜 굳으면 모양이 망가짐).
   물을 섞으면 더 바삭하다는 글이 있으나 검증 안 됨.
5. **고무 씌우기**: 고무공·풍선을 최대한 늘려 왁스 공을 감싼다.
6. **케이블타이로 묶기**.
7. **얼려서 놀기**: 냉동실 5~10분 뒤 누르면 잘 깨진다. 너무 얼리면 돌처럼 딱딱해짐
   (상온에 두거나 전자레인지 20~30초).

## 안전

- 뜨거운 왁스로 화상 위험, 어른 감독 필요.
- 2026년 9월 한국소비자원: 일부 시판 제품에서 MIT·CMIT(가습기 살균제 성분) 검출 발표.
  가상 앱이 안전한 대안이라는 점은 의미가 있다.

|---|---|
| 점토 색 섞기, 마블 무늬 | 있음 (Mixbox, 마블 무늬) |
| 왁스 입히기 | 없음 |
| 고무 씌우기, 케이블타이 | 없음 |
| 얼리기 | 없음 |
| 눌러서 왁스 깨기 (핵심 재미) | 말랑하게 들어가기만 함 |

비슷한 웹 게임: [빠자작](https://www.wakbbuball.com/) — 눌러서 부수기, 색 도감 80종, 랭킹, 글자·사진 새기기.
차별점 후보: 직접 만드는 과정 전체 (섞기 → 왁스 → 고무 → 얼리기 → 깨기).

자료 대부분이 틱톡·블로그라 분량·시간은 검증되지 않았다.
